# Baloncesto

Jednoduchý extrapolační prediktor výsledku basketbalového zápasu. Z opakovaně zadávaných snímků tabule (perioda, zbývající čas, skóre) odhaduje konečné skóre a vykresluje graf. Zápasy se ukládají do localStorage. Podrobnosti v [docs/project-plan.md](docs/project-plan.md).

## Příkazy

```sh
npm install      # instalace závislostí
npm run dev      # vývojový server
npm run check    # formát, lint, typecheck, testy a build
```
